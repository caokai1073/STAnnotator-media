# STAnnotator media

The recorded session the interactive tutorial on the [STAnnotator website](https://caokai1073.github.io/STAnnotator/#tutorial)
replays (`tutorial/data/`, built by `tools/tutorial/build.py` in the source repository), served by GitHub Pages. The
source code is at [caokai1073/STAnnotator](https://github.com/caokai1073/STAnnotator).

This repository keeps a single commit: each new recording replaces it, so old ones do not pile up.
